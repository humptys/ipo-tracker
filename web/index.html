출처: 38커뮤니케이션 ↗

내 다가오는 일정

    이번 주 청약

      상태종목증권사청약상장일 공모가배정매도 실현손익수익률

      아직 기록이 없어요. 오른쪽 위 + 청약 기록에 청약 메시지를 붙여넣어 보세요.

      계산식

      실현손익
      매도금액 − (매도수량 × 공모가) − 매도 수수료·세금 − 청약수수료 − 마통 이자
      수익률
      실현손익 ÷ (매도수량 × 공모가) × 100
      마통 이자
      마통 사용금 × 연 금리 × 대출일수 ÷ 365 (대출일수 = 청약 마지막 날 → 환불일, 주말 포함)
      계산 대상
      매도 기록이 있는 종목만 (일부만 판 경우 판 수량만). 상장대기·배정대기·보유중은 손익에 넣지 않아요.
      매도금액
      매도수량 × 매도가 (나눠 판 경우 모두 합산)

      기간별 수익률 (막대 = 수익률 · 아래 숫자 = 실현손익)

      진입가능척도 대비 수익률

      증권사별 수익률

      종목별 수익률 순위

      실현손익 = 매도금액 − (매도수량 × 공모가) − 매도 수수료·세금 − 청약수수료 − 마통 이자(마통 계산 탭에서 켠 경우). 기간은 첫 매도일 기준이에요.

      이자 = 마통 사용액 × 금리 × 대출일수 ÷ 365. 대출일수는 청약 마감일 → 환불일 (주말 포함, 하루 단위)로 계산해요. 비례 배정 예상 = 청약수량 ÷ 비례경쟁률. 균등 1주는 최소수량만 넣어도 받으니, 여기서는 비례를 노리고 추가로 넣는 돈의 이자와 이익을 비교해요.

      지금 청약 중이거나 예정된 종목이 없어요.

      청약 기록 추가

      공모주 알림 메시지를 그대로 붙여넣으세요. ■ 종목 (증권사) 블록이 여러 개여도 한 번에 저장돼요.

      매도 기록

      수수료·세금을 비워두면 매도금액의 % 로 자동 계산돼요.

      GitHub 연결

      청약·매도 기록을 GitHub 저장소의 파일에 저장해서 PC·핸드폰 어디서든 같은 기록을 봐요. 토큰은 이 기기 브라우저에만 저장돼요.

      토큰 만들기: GitHub → Settings → Developer settings → Fine-grained tokens → Repository access에서 기록용 저장소만 선택 → Permissions의 Contents를 Read and write로. 자세한 순서는 을 보세요.

      증권사 청약수수료

      배정을 1주 이상 받으면 이 금액이 청약수수료 칸에 자동으로 들어가요 (미배정이면 0원). 기본값은 온라인 · 일반 등급 기준이에요 (2026년 11월 조사). 공식 확인은 증권사 홈페이지에서 확인한 금액, 미확인은 비교 사이트 기준이에요. 우대 등급이면 0으로 바꿔 두세요. 표는 기록과 함께 저장돼서 핸드폰·PC에서 똑같이 보여요.

      📖 사용 설명서

      먼저 꼭 읽어 주세요 — 기록 보관

      GitHub에 연결하지 않으면 청약·매도 기록이 지금 쓰는 이 브라우저에만 저장돼요.

      • 다른 기기(핸드폰 ↔ PC)에서는 보이지 않아요.
      • 브라우저 데이터를 지우거나 다른 브라우저로 열면 기록이 사라져요.

      기록을 계속 보관하려면 아래 "GitHub 연결"을 한 번 해 주세요. (무료, 10분 정도)

      GitHub 연결 방법

      1. GitHub 가입 — github.com에서 무료로 가입해요.
      2. 기록용 저장소 만들기 — 오른쪽 위 + → New repository
        이름은 아무거나 (예: ipo-data), 공개 여부는 꼭 Private(비공개) → Create repository
      3. 토큰 만들기 — 프로필 사진 → Settings → 맨 아래 Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
        • Token name: 아무거나 (예: ipo), Expiration: 원하는 기간
        • Repository access: Only select repositories → 2번에서 만든 저장소만 선택
        • Permissions: Repositories 탭 → + Add permissions → Contents 체크 → 오른쪽을 Read and write로
        • Generate token → github_pat_…로 시작하는 토큰을 바로 복사 (한 번만 보여요)
      4. 이 앱에 연결 — 오른쪽 위 ⚙ → 기록 저장소에 내아이디/ipo-data, 토큰 칸에 복사한 토큰 → 연결 테스트 후 저장
        이 기기에만 있던 기록이 있으면 GitHub로 합칠지 물어봐요.
      5. 다른 기기에서도 이 주소를 열고 4번만 하면 같은 기록이 보여요.

      ⚠ 토큰은 비밀번호와 같아요. 다른 사람에게 보내지 마세요. 토큰은 입력한 기기의 브라우저에만 저장돼요.

      청약 기록하기

      • + 청약 기록 → 메시지 붙여넣기: ■ 종목 (증권사) 형식의 청약 알림 메시지를 그대로 붙여넣어요.
      • + 청약 기록 → 직접 입력: 종목명을 치면 38 공모주 일정에서 날짜·공모가가 자동으로 채워져요.
      • 캘린더에서 종목을 누르고 청약할래요를 눌러도 돼요.
      • 청약수량을 넣으면 증거금, 배정을 넣으면 청약수수료가 자동 계산돼요.
      • 환불일에 균등/비례 배정을, 판 뒤에는 매도 추가(날짜·수량·가격)를 입력해요. 매도 후 2영업일 뒤 출금 가능일이 캘린더에 표시돼요.

      탭 안내

      • 캘린더: 공모주 청약·상장·환불 일정 (38커뮤니케이션에서 6시간마다 자동 갱신), ★는 내가 청약한 종목
      • 내 청약: 기록 목록과 상태, 손익·수익률
      • 수익 통계: 기간별·증권사별·종목별 수익률, 진입가능척도·기관경쟁률 대비 수익률 (카드를 옆으로 밀어서 전환)
      • 마통 계산: 마이너스통장으로 증거금을 넣을 때 이자와 손익분기 수익률 미리 계산
